# 千词斩 LexTV — Android TV 英语学习软件(双使用者)

深墨蓝印刷词典风格,专为大屏电视 + 遥控器设计。FSRS-4.5 间隔重复调度。

## v3.6 新特性
### 👥 双使用者一键切换
主页「切换使用者」:**爸爸·金融投资版**(全功能) ⇄ **弟弟·中考冲刺版**(隐藏实景模拟/界面对照等金融内容,词库只显示中考词)。两人学习进度、词库开关、设置**完全独立**,互不影响。

### 🔊 发音引擎 v2(根治句子漏读)
旧版所有发音走有道词典接口,该接口**只支持单个单词**——短语和句子直接报错被静默跳过,这就是"句子只读一半/中间漏读"的根源。v3.6 彻底重做:
- 整句**一次合成、不再分段**:百度翻译在线合成(主源)→ 百度云语音合成(备源)→ 单词仍用有道词典音
- 下载后用**原生 MediaPlayer** 播放(不再依赖 WebView Audio),并缓存到本地——重复播放秒开、离线可用
- 不使用电视系统 TTS(部分电视不可用)

### ⌨️ 拼写挑战
听发音、看释义,用遥控器在屏幕字母键盘上拼出单词。首字母默认给出,💡可提示(扣分),拼错的词自动加密复习。中考拼写题就这么练。

### 🎒🎓 中考 + 高考词库(v3.7 已填充)
弟弟档案内置两个独立词库,按考纲严格分类、互不重叠:
- **🎒 中考核心词汇**:义务教育课标核心词,A–Z 共约 1280 词(`zk_*.json`)
- **🎓 高考进阶词汇**:高中新增词(不含中考已有词),A–Z 共约 975 词(`gk_*.json`)

每条含:单词 · 音标 · 词性中文释义 · **原创英文例句** · **例句整句中文翻译**(供例句填空显示)。全部经脚本自查:JSON 合法、两库零重叠、字段完整。

**继续扩充**:按同样格式新增 `zk_*.json` / `gk_*.json`,在 `manifest.json` 对应词库的 `files` 数组登记即可。词条格式:
```json
["单词","音标","词性 中文释义","英文例句","例句的中文翻译"]
```
manifest 里词库的 `profile` 字段:`"teen"`=只给弟弟版,`"fin"`=只给爸爸版,不写=两边共用。

## 自动更新
设置 → 检查更新:App 会读取本仓库最新 Release(tag 形如 `v3.5-6`,末尾为 versionCode),有新版即可一键下载安装,学习进度完整保留。每次 push 后 GitHub Actions 自动打包 APK 并发布 Release。

## 打包安装
1. push 本仓库,Actions 自动运行 “Build APK”
2. Release 页下载 `LexTV.apk`(或下载 Actions 工件),U 盘拷入电视安装
3. 之后的升级直接在电视上“检查更新”即可

## 添加词书(两个口子)
- 口子A:把 .json 放进 `app/src/main/assets/decks/`,在 manifest.json 登记,重新打包
- 口子B(免打包):电视上复制到 `/sdcard/Android/data/com.lextv.app/files/decks/`,重启应用自动加载
- 词条格式:`[["单词","音标","词性 中文释义","英文例句"], ...]`
